# Local Grocery Price Finder - Demo Video Script

## 1. Giriş (30 saniye)
- Proje amacı ve özellikleri
- Kullanılan teknolojiler (Django, DRF, JWT, Bootstrap)
- Proje mimarisi

## 2. Kullanıcı Arayüzü (45 saniye)
- Ana sayfa tasarımı
- Responsive tasarım gösterimi
- Kullanıcı girişi ve kayıt formları
- Favoriler sayfası

## 3. Temel Özellikler (60 saniye)
- Ürün arama
- Filtreleme (mağaza, konum)
- Sıralama (fiyat)
- En ucuz seçenekleri vurgulama

## 4. Kullanıcı Hesabı (30 saniye)
- Kayıt olma
- Giriş yapma
- Favorilere ekleme
- Favorileri görüntüleme

## 5. Performans ve Güvenlik (30 saniye)
- Sayfalama
- Token tabanlı kimlik doğrulama
- Hata yönetimi
- Yükleme göstergeleri

## 6. Deployment (15 saniye)
- GitHub Actions CI/CD
- Heroku deployment
- Canlı demo
